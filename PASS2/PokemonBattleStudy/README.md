# PokemonBattleStudy

Java 클래스와 객체지향 개념을 복습하기 위해 만든 간단한 콘솔 포켓몬 배틀 프로그램입니다.

## 사용한 내용

- 클래스와 객체
- 필드
- 생성자
- `this`
- 메서드
- `private`, `public`
- getter
- 객체를 메서드의 매개변수로 전달
- 배열
- Scanner
- if / else
- while / for
- Random

이번 버전에서는 Collection(ArrayList)은 사용하지 않았습니다.

## 실행 방법

1. IntelliJ IDEA 실행
2. `PokemonBattleStudy` 폴더 열기
3. `src/Main.java` 열기
4. `main()` 옆의 실행 버튼 클릭
5. 콘솔에서 번호를 입력해 게임 진행

## 프로젝트 구조

```text
PokemonBattleStudy
└── src
    ├── Main.java
    └── Pokemon.java
```

## 게임 기능

- 피카츄 / 파이리 / 꼬부기 / 이상해씨 선택
- 상대 포켓몬 선택
- 일반 공격
- 포켓몬별 특수 기술
- 타입 상성
- 회복
- 상태 확인
- 상대 포켓몬 자동 공격
- 승패 판정
- 재대결
