# CharacterBattle

상속·오버라이딩을 복습하고 다형성을 응용하는 작은 Java 턴제 전투입니다.
기존 CharacterStudy는 보관하고, 전투를 추가한 이번 버전을 별도 프로젝트로 만들었습니다.

## IntelliJ 실행

1. 압축을 풀고 이 README와 src가 들어 있는 CharacterBattle 폴더를 엽니다.
2. src/Main.java의 main 옆 실행 버튼을 누릅니다.
3. SDK가 없다고 나오면 File > Project Structure > Project > SDK에서 설치된 JDK를 고릅니다.
4. Run 창에서 메뉴 번호를 입력하고 Enter를 누릅니다.

현재 PC의 openjdk-26을 기본 SDK 이름으로 지정했습니다. 외부 라이브러리와 빌드 도구는 필요 없습니다.

## 전투 규칙

몬스터 체력은 120입니다. 직업을 선택하면 능력치를 먼저 확인합니다. 1번은 확정, 2번은 직업 다시 선택, 0번은 종료입니다. 확정한 뒤 매 턴 일반 공격, 특수 공격, 회복 중 하나를 선택합니다.
일반 공격은 제한이 없고 특수 공격과 물약은 각각 2회입니다.
물약은 최대 체력을 넘지 않는 범위에서 30 회복합니다.
행동 후 몬스터가 살아 있으면 14~21 피해로 반격합니다. 회복도 한 턴을 사용합니다.
잘못된 입력, 횟수 소진, 최대 체력에서의 회복 시도는 턴을 소비하지 않습니다.
몬스터를 처치한 턴에는 반격하지 않습니다. 한쪽 체력이 0이면 전투가 끝납니다.
0번은 직업 선택에서는 종료, 전투 중에는 도망입니다. 입력 종료도 전투 중단으로 처리합니다.
게임 한 번이 끝나면 프로그램이 종료됩니다. 다시 하려면 실행 버튼을 누릅니다.

| 직업 | 체력 | 일반 공격 | 특수 공격 |
|---|---:|---|---|
| 전사 | 120 | 21 | 강타 36 |
| 마법사 | 85 | 22 | 화염구 44 |
| 궁수 | 100 | 20~25 무작위 | 연속 사격 34 |
| 도적 | 90 | 16, 약 30% 확률로 32 | 기습 32 |

능력치는 코드 흐름을 비교하기 위한 예제 값입니다.

## 시연 예시

1(전사 선택), 1(확정), 2(특수 공격), 2(특수 공격), 1(공격), 3(회복), 1(공격), 1(공격)

각 번호마다 Enter를 누릅니다. 이 순서에서는 전사가 승리합니다.
몬스터 반격 피해는 매번 달라지므로 남은 체력은 실행마다 다릅니다.

## 파일과 공부할 부분

- Main.java: 직업 선택, 다형성 호출, 반환값 사용, 한 턴의 순서와 종료 판정
- GameCharacter.java: 공통 필드와 생성자, int 반환형, 체력 감소와 회복
- Warrior.java / Mage.java: 대표적인 메서드 오버라이딩과 피해량 반환
- Archer.java / Rogue.java: 난수와 조건문으로 공격 내용 변경

선언과 주요 실행 문장 위에 설명 주석을 넣었습니다.
먼저 damage = player.attack() → return damage → monsterHp -= damage 순서를 읽어 보세요.
PPT는 모든 코드를 설명하지 않고 이 흐름과 대표 오버라이딩 코드만 발췌합니다.

상속·오버라이딩은 공유한 1학기 수업 저장소에서 확인한 내용입니다.
https://github.com/yoosw0522/java1/tree/master/src/ai0604/inheritance

부모 타입 변수로 자식 객체를 다루는 형태의 다형성은 확인한 수업 예제에서 찾지 못해 추가 학습으로 표시했습니다.
어려운 부분은 호출 흐름과 공격·반격 순서입니다. 실제로 이해가 어려운 부분을 복습하며 발표 설명을 조정하세요.

## 코드 개선 방향

1. Main에 입력과 전투 처리가 함께 있어 길어졌습니다. 이후 playTurn 같은 메서드로 나눌 수 있습니다.
2. 필드에 접근 제한자를 생략했습니다. private과 필요한 메서드로 값의 변경을 관리할 수 있습니다.
3. 공격 보너스나 회복량을 숫자로 직접 적었습니다. 이름 있는 필드나 상수로 정리할 수 있습니다.

일부러 오류를 넣은 것은 아니며, 위 내용은 다음 복습에서 적용할 수 있는 개선안입니다.

## 터미널 실행

```text
javac -encoding UTF-8 -d out src/Main.java src/GameCharacter.java src/Warrior.java src/Mage.java src/Archer.java src/Rogue.java
java -Dfile.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main
```
